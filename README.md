# Network Traffic Anomaly Detection  This project explores anomaly detection in network traffic using machine learning models. It is based on a synthetic dataset that simulates network activity

# Network Traffic Anomaly Detection
## 📁 Dataset

This project uses the **Synthetic Network Traffic Anomaly Detection Dataset** available on Kaggle:

🔗 [Dataset Link](https://www.kaggle.com/datasets/vidhikishorwaghela/synthetic-network-traffic)

> **Note:** The dataset is not included in this repository due to distribution restrictions. Please download it from Kaggle and place it in the project directory to run the notebook.

This work is inspired by and builds upon the notebook by [Vidhikishor Waghela](https://www.kaggle.com/code/vidhikishorwaghela/network-traffic-anomaly-detection).
